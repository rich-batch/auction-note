# 조사 노트: 경매 명도 어려운 물건
기준일: 2026-09-19

## 중복 판단
- 이미 있는 글: 겹침 없음 (낙찰금·대출·입찰·공매와는 다른 주제)
- 같은 카테고리 다른 키워드 #19(경매 명도 절차): 부분 구분 필요
  - #19는 명도 **절차 단계별 진행**에 초점
  - 이 글 #6은 **명도 문제 있는 물건 사전 확인·비용·비용 절감**에 초점
  - 결론: 단독 작성 가능. #19와는 질문이 다름

## 경쟁 글 비교
(사람이 직접 구글에서 "경매 명도 어려운 물건" 검색하여 1페이지 5개 글 확인 필요)

예상되는 경쟁 글 유형:
- 법원 안내: 명도 절차 일반
- 블로그: 명도 비용 계산, 경매 팁
- 부동산 커뮤니티: 명도 경험담
- 언론: 명도 분쟁 사건 기사

## 차별점
- 사전 확인 방법을 현황조사 보고서와 실지조사(현장 방문)의 단계별 절차로 구체화
- 점유자 유형별(세입자/무단점거/구 소유자) 다른 대응 방법과 비용을 설명
- 명도 비용을 표로 정리: 법원 수수료(0.5~1%), 변호사비(150~300만 원), 집행관비(수십만~200만 원) 등 구체적 금액 범위 제시
- 체크리스트 형식의 위험 물건 판단 가이드: 입찰 전 확인 사항과 낙찰 후 초기 조치로 구분
- 세입자 보증금 우선변제권의 실제 영향을 계산 예시로 설명(낙찰가 3억 → 세입자 보증금 1.5억 우선 지급 → 낙찰자 실제 수익 1.5억)
