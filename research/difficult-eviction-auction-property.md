# 조사 노트: 경매 명도 어려운 물건
기준일: 2026-09-19

## 중복 판단

**이미 있는 글과의 관계:**
- "경매 낙찰금, 세금 더하면 얼마 될까" → 명도·수리비 항목만 언급, 중복 아님
- "경매 입찰 방법, 보증금부터 얼마일까" → 입찰 절차, 중복 아님
- "공매와 경매, 낙찰 후에 갈린다" → 명도 절차를 다루지만, 공매·경매 비교 중심이며 "어려운 물건"에 특화 아님

**같은 카테고리 미작성 키워드:**
- "경매 명도 절차"(priority 19) → 일반적 명도 절차, 내 글은 "어려운 물건" 특화
  - 명도 절차: 모든 경매 물건의 표준 절차
  - 경매 명도 어려운 물건: 세입자 거부, 점유자 제거 어려움, 비용 절감, 낙찰 전 확인 방법
  - 내 글에서 명도 절차의 기본을 간단히 설명하되, 전체 흐름 설명은 priority 19에 맡김

**결론:** 단독 작성 가능. "어려운 상황의 조기 발견"과 "문제 물건 판별"을 차별점으로 삼음

차별점:
- **낙찰 전 확인 체크리스트** → 현재 경쟁 글들은 낙찰 후 절차만 다룸. 세입자 존재 여부, 권리 종류, 전세금 규모를 미리 확인하는 법을 구체적으로 설명
- **세입자 유형별 차이** → 대항력 없는 월세(2~4주) vs 대항력 있는 전세(1년)의 명확한 구분으로, 입찰 판단 기준 제시
- **비용 절감의 실제 의사결정** → 협상(이사비 제안)이 법절차(500만원 이상)보다 경제적인 이유를 수치로 비교
- **공식 법령 직인용** (민사집행법 제136조, 제200조) + 구체적 기간과 비용 수치

- 2026년 이후 최신 개정안이 있는지 (6개월 기한 완화 논의는 진행 중이지만 현행법 미변경)
