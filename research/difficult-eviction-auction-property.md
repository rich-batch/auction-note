# 조사 노트: 경매 명도 어려운 물건
기준일: 2026-09-19

## 중복 판단
- 경매 명도 절차(priority 19): 명도 절차 전체 가이드 / 이 글: 세입자/점유자가 있는 "어려운" 물건에 특화 → 비중복 (보완 가능)
- 경매 권리금 처리(priority 23): 상권 권리금 / 이 글: 명도 난이도 → 비중복
- 경매 우선순위권(priority 30): 우선순위 개념 설명 / 이 글: 명도 실행 관점 → 비중복

결론: 단독 작성. 차별점 있음

차별점:
- 명도 어려운 물건의 정의: 점유자 있는 물건, 특히 세입자와의 관계
- 낙찰 전 확인 체크리스트 (현장답사, 문서 확인, 세입자 대항력/우선순위권 판단)
- 비용 절감 전략: 협상(이사비) vs 소송/집행 비교
- 기간 예측: 인도명령(1~3개월) vs 명도소송(4~6개월) vs 강제집행(3개월)
- 대항력·우선순위권 개념을 실무 관점으로 설명

## 확인하지 못한 것
- 강제집행 예납금의 구체적 금액 (법원별·물건 규모별 차이)
- 명도 실비의 실제 범위 (현장 상황에 따라 크게 달라짐)
- 세입자 타입별 명도 난이도 (임차인/주택임차인/상가임차인/불법점유자 등의 구체적 기간/비용 차이)
- 대항력 있는 임차인이 우선변제권도 없을 때의 명도 가능 여부 (법적으로는 명도 가능하나 실무상 복잡함)
