# 필수 페이지 (소개 · 개인정보처리방침 · 연락처)

애드센스 심사는 "이 사이트를 운영하는 게 누구고, 무슨 정보를 다루고, 문제가 있을 때 어떻게 연락할지"를 최소한으로 확인한다. 이 3페이지가 없으면 콘텐츠가 아무리 좋아도 거절 사유가 된다.

## 현재 상태 확인부터

이미 만들어져 있을 수 있다. 먼저 확인하라.

```bash
ls content/about.md content/privacy.md content/contact.md 2>&1
```

있으면 내용이 최신인지만 확인(연락처 이메일, 블로그 이름, 최종 수정일)하고 끝낸다. 없는 것만 아래대로 만든다.

## 공통 front matter

3페이지 모두 목록이 아니라 사이트 메뉴에 뜨는 정적 페이지다. Hugo에서 페이지를 메뉴에 넣으려면 front matter에 `menu.main.weight`를 지정하면 된다(PaperMod가 `site.Menus.main`을 순서대로 렌더링).

```yaml
---
title: "제목"
date: {오늘 날짜}
menu:
  main:
    weight: 10   # 소개=10, 개인정보처리방침=20, 연락처=30 순서
ShowToc: false
ShowReadingTime: false
ShowShareButtons: false
ShowPostNavLinks: false
hidemeta: true
---
```

## 소개 (`content/about.md`, weight: 10)

이 블로그가 무엇을 다루는지, 누가 왜 쓰는지, 정보성이지 투자 자문이 아니라는 점을 담는다. 실제 겪은 계기가 있으면 한 문단 넣어라(지어내지 마라 — 없으면 "~을 정리하는 블로그입니다" 정도로 담백하게).

포함할 것:
- 블로그가 다루는 범위(경매·공매의 어느 부분)
- 글을 쓰는 방식(공식 자료·법령 확인 후 작성, 출처 표기)
- 정보 제공 목적이며 투자 권유·법률 자문이 아니라는 문장
- 연락처 페이지로의 링크

## 개인정보처리방침 (`content/privacy.md`, weight: 20)

애드센스 심사에서 가장 자주 보는 페이지다. 정형화된 내용이라 항목만 갖추면 된다.

포함할 것(구글 애드센스 게재 시 필수):
1. 수집하는 정보(방문 로그, 쿠키 — 회원가입이 없으면 "직접 수집하는 개인정보 없음"으로)
2. 광고 서비스와 쿠키 — 구글 애드센스 사용, 제3자 쿠키로 맞춤 광고 가능, [구글 광고 정책](https://policies.google.com/technologies/ads)과 [광고 설정](https://adssettings.google.com/) 링크
3. 정보 이용 목적
4. 제3자 제공 여부
5. 문의처(연락처 페이지 링크)
6. 방침 변경 안내 + 최종 수정일

**애드센스 승인 전이라도 이 문구는 미리 넣어 둔다.** 심사 자체가 "광고를 게재할 준비가 된 사이트"인지를 보기 때문이다.

## 연락처 (`content/contact.md`, weight: 30)

이메일 하나면 충분하다. 실제로 확인 가능한 주소를 넣는다(사용자에게 어느 이메일을 쓸지 반드시 확인 — 지어내지 마라).

## 확인

```bash
hugo -D -d <임시폴더>
```
빌드 후 홈페이지 HTML에서 메뉴 순서(소개 → 개인정보처리방침 → 연락처)와 각 페이지가 실제로 열리는지 확인한다. 모바일 폭에서도 메뉴가 안 잘리는지 브라우저로 확인하는 건 사람 몫이다.
