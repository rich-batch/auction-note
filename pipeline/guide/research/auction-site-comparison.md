# 조사 노트: 경매 사이트 추천
기준일: 2026-09-19

## 중복 판단

| 대상 | 겹침 정도 | 이유 |
|---|---|---|
| 경매 낙찰금, 세금 더하면 얼마 될까 | 없음 | 비용 계산 중심 vs 사이트 비교 중심 |
| 경매 입찰 방법, 보증금부터 얼마일까 | 없음 | 입찰 절차 중심 vs 플랫폼 선택 중심 |
| 무주택자 경락잔금대출 | 없음 | 대출 상품 중심 vs 사이트 비교 중심 |
| 공매와 경매, 낙찰 후에 갈린다 | 없음 | 공매/경매 구분 vs 사이트 플랫폼 비교 |
| 경매란? 법원경매와 공매의 차이 | 없음 | 개념/정의 중심 vs 사용 플랫폼 비교 |

**같은 카테고리 이웃 키워드:**
- 2번 경매 입찰 방법: 절차형이므로 중복 없음
- 11번 법원경매 무료검색: 법원경매정보 사이트 사용법만 다루므로 중복 없음
  - 차별점:
- 경쟁 글은 유료 사이트 요금·기능을 블로그 출처로 나열하지만, 이 글은 "권리분석 서류는 법이 공개를 의무화한 자료"라는 점을 민사집행법 제105조·민사집행규칙 제55조·국세징수법 제77조 원문으로 보여 준다
- 무료로 안 되는 자료(등기부 열람 700원, 전입세대확인서 — 경매참가자 신청 자격)를 법령으로 구분
- 유료 서비스는 자료가 아니라 시간을 판다는 판단과, 볼 물건 수를 기준으로 한 선택 기준
- 경매마당을 "공식 사이트"로 소개한 이전 글의 오류 바로잡음(민간 서비스), 검증 못 하는 요금 수치는 싣지 않음

- 검색 편의성과 인터페이스 사용성을 사용자 관점에서 평가
- 무료/유료 비용 대비 정보량 분석으로 가성비 판단 기준 제시

### 주요 발견사항

**공식 사이트 (무료):**
- 대법원 법원경매정보: 회원가입 불필요, 기본 정보 제공
- 캠코 온비드: 공매 중심 (경매마당에서도 접근 가능)
- 경매마당: 무료면서도 유료 사이트 수준의 상세 정보 제공

**유료 민간 사이트:**
- 월 2만원대 ~ 연 150만원대까지 다양
- 탱크옥션이 가성비, 지지옥션이 가장 상세
- 굿옥션은 뉴스 기사 검색, 스피드옥션은 동영상 강좌

**사용자층별 추천 가능성:**
- 입문자 → 무료 사이트만 충분
- 활발한 투자자 → 유료 구독으로 효율 향상
- 초보자 → 경매마당으로 상세 정보 확인 후 유료 사이트 전환
