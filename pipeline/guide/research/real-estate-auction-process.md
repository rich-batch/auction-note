**결론**: priority 4인 "경매 낙찰 후 절차"와 역할 구분 필요. 이 글(priority 13)은 입찰 준비 → 입찰 → 낙찰 → 잔금 → 명도·등기까지의 전체 흐름을 한눈에 보는 타임라인/체크리스트 형식으로, 각 단계별 핵심 준비사항과 기간을 다룬다. priority 4 "낙찰 후 절차"는 낙찰 후 단계만 깊이 있게 다룬다 → 차별화 가능.

## 차별점
- 법령(민사집행법·규칙 조문) 기반 정확한 기간과 기한(각 수치마다 조문 명시하여 근거 명확)
- 각 단계별 "무엇을 해야 하는가" 타임라인 + 표 (독자가 지금 단계를 알고 다음을 준비하게)
- 흔한 실수("낙찰=소유권 이전", "잔금 기한 놓치기", "점유자 문제") 명시하고 법령으로 뒷받침
- 입찰 방식(기일입찰/기간입찰)에 따른 기간 차이 명확히 구분

## 확인하지 못한 것
- 실제 구글 한국 검색 1페이지 경쟁 글 (검색 직접 확인 필요)
- 낙찰가 확정(매각기일) → 잔금 기한 사이의 정확한 기간(민사집행법 제142조에서 "정부고시 기간"으로 규정되어 있음 → 현재 시점에 정부고시 기간 확인 필요)
- 등기 소요 시간 (법원/법무사 업무 기간)

## 차별점

차별점:
- 이전 초안이 "감정가 공고 2주(규칙 제36조)", "입찰 공고부터 3주(규칙 제53조)", "잔금은 정부고시 기간", "등기 1~2주"처럼 조문과 맞지 않는 기한을 적었던 것을 걷어내고, 실제 조문(규칙 제55·56·68·78조, 법 제84·109·126·142조)으로 기한을 다시 세움
- 개시결정~첫 매각기일은 법정 기간이 없다는 점과, 공고 이후 구간은 법정 기한으로 움직인다는 점을 구분
- 이 블로그가 법원경매정보에서 조회한 실제 사건(서울남부 2025타경10947)의 기일 기록으로 개시결정→첫 매각 8개월, 유찰 한 번당 5~7주가 더해지는 실제 시간을 보여 줌
