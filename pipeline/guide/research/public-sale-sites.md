## 차별점

- 이 글이 1페이지 글들보다 더 주는 것:
  1. **온비드 중심 통합 설명**: 온비드가 국세청·관세청 물건까지 다루는 통합 플랫폼임을 명확히
  2. **각 기관별 물건 특성 구분**: 온비드(국유·공공·압류 통합), 국세청(체납자산), 관세청(압류·적발)의 차이
  3. **입찰 방식의 실제 차이**: 온비드 100% 전자입찰 vs 국세청·관세청 별도 채널의 구체적 절차
  4. **사용자 입장의 판단 기준**: 물건 종류에 따라 어느 사이트에서 찾을지 선택하는 실용적 가이드
  5. **1페이지의 한계**: 기존 글들은 통합 조회 지도나 법원경매 중심이며, 각 공매 사이트 자체의 물건 특징 비교가 부족함

## 확인하지 못한 것
- 각 사이트별 정확한 **수수료 비율** (온비드 공식 페이지에서 확인 안 됨 → 고객센터 문의 필요)
- **관세청 공매의 입찰 절차 상세** (유니패스 시스템에 접근 불가)
- 각 사이트별 **낙찰 후 절차의 구체적 차이** (공식 자료에 명시되지 않음)
- **국세청 온라인 입찰 별도 시스템 여부** (온비드 통합으로 진행되는 것으로 보임)

## 특기 사항
- 온비드는 국세청, 관세청, 지자체 등 다양한 기관의 공매물건을 통합 관리
- 경쟁 글들은 법원경매나 통합 조회 지도 중심으로, 각 기관별 특화 설명 부족
- "공매 물건 조회 사이트"는 실제 사용자가 많이 검색하지만, 기존 글들은 사이트 비교보다 절차 설명 중심
